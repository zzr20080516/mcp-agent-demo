# MCP-agent-demo
MCP + AI Agent Skill 实战项目

## 📖 项目介绍
本仓库是 AI智能体 / MCP应用开发 的学习作品集。
目标：练习 Agent Skill 编写、MCP服务部署、自定义MCP Server开发，实现大模型工具调用与自动化能力。

## 🛠️ 技术栈
- PowerShell：系统自动化脚本
- Node.js：MCP Server 开发
- Python：备选MCP服务实现
- MCP Protocol：模型上下文协议

## 📌 项目计划
1. Agent Skill 案例开发
2. MCP Server 部署调试
3. 工具调用、运维自动化实战
